# VMware 输入窗口修复计划

用户已确认：快捷键触发后，用覆盖所有显示器的透明输入窗口接管拖选，松开后隐藏窗口再截图。

## 范围和约束

- 本目录继续保存设计、计划与验收记录；源码位于 stealth_screenshot，测试位于根目录。
- 独立 Win32 UI 线程拥有分层置顶工具窗口；不显示边框、选框或任务栏按钮。
- 使用虚拟桌面物理坐标，支持负坐标。窗口 alpha=1/255；alpha=0 会穿透输入，故不宣称像素完全不变。
- 开始时激活窗口并捕获鼠标；按下后锁定起点，忽略重复按下；松开后隐藏、释放鼠标、同步桌面合成，再调用捕获逻辑。
- Esc、右键、30 秒超时、失去输入捕获或显示配置变化均取消；取消不截图、不覆盖剪贴板。
- 保留旧鼠标钩子文件供回归参考，但主流程不启动它。
- 日志仅包含事件、坐标和错误；此次不提交或推送 GitHub。
